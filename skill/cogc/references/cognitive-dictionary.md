# Cognitive Dictionary

The dictionary provides stable labels for repeated cognitive/operational concepts. In v0.2.0 detection is advisory only: CogC records matching dictionary references in the receipt but does not replace protected source text with dictionary codes.

Initial entries:

- CGC-001 — REUSE_BEFORE_BUILD
- CGC-002 — SOURCE_INSPECTION_REQUIRED
- CGC-003 — RUNTIME_PROOF_REQUIRED
- CGC-004 — EXTERNAL_ACTION_RECEIPT_REQUIRED
- CGC-005 — OWNER_APPROVAL_REQUIRED
- CGC-006 — CONTRADICTORY_EVIDENCE
- CGC-007 — PROVIDER_DEGRADED
- CGC-008 — ESCALATION_REQUIRED

Dictionary substitution can become more aggressive only after a receiving-agent eval demonstrates that the codes preserve downstream decisions.
